# 🛡️ درع الكاشير (SAR Cashier Currency Shield)
### نظام حماية كاشير نقاط البيع لتحويل العملات الأجنبية وحساب الباقي بالريال السعودي بدقة 100%

---

## 🌟 المشكلة والحل الجذري لحماية الكاشير من عجز الصندوق
عندما يدفع العميل بعملة أجنبية، يقع الكاشير تحت ضغط كبير ومخاطر حقيقية لتحمل أي نقص أو زيادة في الصرف:
1. **الخطأ في اتجاه العملية (ضرب أم قسمة؟)**: تم إلغاء الحاجة للحساب اليدوي، فالنظام يعتمد **سعر شراء العملة المعتمد** ويجري العملية تلقائياً.
2. **أخطاء الفواصل والتقريب المالي**: جميع العمليات تتم بحسابات دقيقة بالهللة وتفادي أخطاء الأرقام العشرية.
3. **الخطأ في قراءة الأرقام**: تم تزويد النظام بـ **التفقيط المالي التلقائي** (كتابة المبلغ بالكلمات العربية الفصحى مثل: *مائتان وخمسة وعشرون ريالاً سعودياً فقط لا غير*).
4. **الخطأ في سحب الأوراق النقدية**: ميزة **مساعد فئات النقد السعودي** توضح للكاشير الأوراق والقطع المعدنية الواجب تسليمها بدقة (مثلاً: ورقة 200، ورقة 20، ورقة 5).
5. **النزاع مع العميل**: **بروتوكول التأكيد الشفهي** يعطي الكاشير جملة واضحة ومقروءة بصوت عالٍ أو مسموع عبر النظام ليسمعها العميل قبل تسليم النقد.
6. **مطابقة الشفت والجرد اليومي**: إمكانية **طباعة سند حراري (80mm)** يوضع في الدرج مع العملة الأجنبية، وسجل كامل لعمليات الشفت لمطابقة الدرج بدون أي عجز.

---

## 🚀 المميزات الرئيسية
- 💵 **دعم شامل للعملات**: الدولار الأمريكي (USD)، اليورو (EUR)، الجنيه الإسترليني (GBP)، الدرهم الإماراتي (AED)، الدينار الكويتي (KWD)، الدينار البحريني (BHD)، الريال العماني (OMR)، الريال القطري (QAR)، الجنيه المصري (EGP)، وغيرها.
- 🧮 **وضعان للعملية**:
  - دفع فاتورة كاملة أو جزئية + إرجاع الباقي بالريال السعودي.
  - صرف وتحويل نقدي مباشر بدون فاتورة.
- ⌨️ **لوحة أرقام لمسية مدمجة (Touch Numpad)** لشاشات نقاط البيع اللمسية وأزرار الفئات السريعة للعملة.
- 🔒 **لوحة أسعار الصرف المعتمدة**: محمية برمز مرور (PIN الافتراضي: `1234`) لمنع التعديل غير المصرح به.
- 🧾 **طباعة سندات حرارية متوافقة مع طابعات الفواتير 80mm**.
- 📊 **سجل الشفت ومطابقة محتويات الدرج وتصدير Excel (CSV)**.
- 🔊 **تغذية صوتية فورية ونطق عربي آلي**.
